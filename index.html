1. What to know for the ACT

The ACT Math section can include trigonometric ratios and circle problems. ACT’s mathematics standards also list unit-circle trigonometry as a skill. For this topic, the most useful skills are recognizing common angles, reading sine and cosine from coordinates, finding tangent, and using signs and reference angles.

Study priority: Learn the unit-circle values for 0°, 30°, 45°, 60°, and 90° first. The other common angles use the same values with different signs. You usually do not need to memorize every point separately.

The ACT describes its math content as skills generally learned through the beginning of grade 12. Its geometry description specifically includes trigonometric ratios; its mathematics standards include unit-circle trigonometry. A unit-circle question may appear as a direct value question or be embedded in a larger problem.

2. The core idea: a circle of radius 1

A unit circle is a circle centered at the origin, (0, 0), with radius 1. A point on it at angle θ has coordinates:

(x, y) = (cos θ, sin θ)
So cos θ = x, sin θ = y, and tan θ = y/x = sin θ/cos θ when x ≠ 0.

Because every point on the circle is exactly 1 unit from the origin, its coordinates satisfy x² + y² = 1. Replacing x with cos θ and y with sin θ gives the identity cos² θ + sin² θ = 1.

3. Degrees and radians

Degrees divide one full turn into 360 parts. Radians measure an angle by comparing arc length to radius. One full circle is both 360° and 2π radians.

Degrees0°30°45°60°90°180°360°
Radians0π/6π/4π/3π/2π2π

Degrees → radians

Multiply by π/180.

150° × π/180 = 5π/6

Radians → degrees

Multiply by 180/π.

7π/4 × 180/π = 315°

Memory cue: In a radian measure, π radians is a half-turn (180°); π/2 is a quarter-turn (90°).

5. Signs by quadrant and reference angles

Angles are usually measured counterclockwise from the positive x-axis. The quadrant determines whether the coordinates—and therefore sine and cosine—are positive or negative.

QuadrantAngle rangecos θ (x)sin θ (y)tan θPositive function(s)
I0°–90°+++All
II90°–180°−+−Sine
III180°–270°−−+Tangent
IV270°–360°+−−Cosine

Reference angle means the small acute angle between the terminal side and the x-axis. It supplies the absolute values of sine, cosine, and tangent; the quadrant supplies the signs.

  • Quadrant II: reference angle = 180° − θ. Example: 150° has reference angle 30°.
  • Quadrant III: reference angle = θ − 180°. Example: 225° has reference angle 45°.
  • Quadrant IV: reference angle = 360° − θ. Example: 330° has reference angle 30°.
Example: For 150°, the reference angle is 30°. Since 150° is in Quadrant II, sine is positive and cosine is negative. Therefore sin 150° = 1/2 and cos 150° = −√3/2.

Axis angles: On the x-axis, coordinates are (±1, 0); on the y-axis, (0, ±1). Sine and cosine are the coordinate pair. Tangent is 0 on the x-axis, and undefined on the y-axis.

6. How to solve unit-circle questions

  1. Identify what is asked: sine is y, cosine is x, tangent is y/x.
  2. Locate the angle: convert radians to degrees if that makes it easier to recognize.
  3. Find its reference angle: compare to 30°, 45°, or 60°.
  4. Use the special-angle value.
  5. Apply the quadrant sign.
  6. Check for undefined tangent: if cosine is 0, tangent is undefined.

Worked examples

Example A: Find sin(5π/6).
5π/6 = 150°. Its reference angle is 30°. Quadrant II has positive sine, so sin(5π/6) = 1/2.
Example B: Find cos(7π/4).
7π/4 = 315°. Its reference angle is 45°. Quadrant IV has positive cosine, so cos(7π/4) = √2/2.
Example C: Find tan(2π/3).
2π/3 = 120°. Its reference angle is 60°. In Quadrant II tangent is negative; tan 60° = √3. Therefore tan(2π/3) = −√3.
Example D: If the terminal point is (−3/5, 4/5), find sin θ, cos θ, and tan θ.
Coordinates are (cos θ, sin θ). So cos θ = −3/5, sin θ = 4/5, and tan θ = (4/5)/(−3/5) = −4/3.

7. Useful identities and patterns

  • sin² θ + cos² θ = 1 for every angle.
  • tan θ = sin θ / cos θ, as long as cos θ ≠ 0.
  • Complementary angles: sin(90° − θ) = cos θ and cos(90° − θ) = sin θ.
  • One full turn: adding or subtracting 360° (or 2π) lands at the same point. These are coterminal angles.
  • Negative angle: moving clockwise gives cos(−θ) = cos θ and sin(−θ) = −sin θ.
Common traps
  • Mixing up the coordinate order: it is (cos θ, sin θ), not (sin θ, cos θ).
  • Using the right reference value but forgetting the sign in Quadrants II–IV.
  • Confusing √3/2 and 1/2: at 30°, sine is 1/2 and cosine is √3/2; at 60°, they switch.
  • Writing a numeric value for tangent at 90° or 270°; it is undefined.
  • Forgetting that a calculator must be in the correct mode. If the question gives degrees, use degree mode; if radians, use radian mode.

Connection to right-triangle trigonometry

In a right triangle, sin θ = opposite/hypotenuse, cos θ = adjacent/hypotenuse, and tan θ = opposite/adjacent. On the unit circle the hypotenuse is the radius, which equals 1. That is why the horizontal coordinate equals cosine and the vertical coordinate equals sine.

8. Quick practice

Try these without looking at the answers. Give exact values; leave square roots in simplified form.

  1. Convert 240° to radians.
  2. Find sin(5π/4).
  3. Find cos(11π/6).
  4. Find tan(2π/3).
  5. For the point at angle 225°, state its coordinates on the unit circle.
  6. If sin θ = −√3/2 and θ is in Quadrant IV, what is cos θ?
  7. Find sin 390°.
  8. What is tan(π/2)?
  9. If cos θ = 5/13 and θ is in Quadrant IV, find sin θ and tan θ.
  10. A point on the unit circle is (−√2/2, √2/2). What is the smallest positive angle in degrees?
Show answers and explanations
  1. 240° × π/180 = 4π/3.
  2. 5π/4 = 225°, reference angle 45°; both coordinates are negative in Quadrant III, so −√2/2.
  3. 11π/6 = 330°, reference angle 30°; cosine is positive in Quadrant IV, so √3/2.
  4. 2π/3 = 120°, reference angle 60°; tangent is negative in Quadrant II, so −√3.
  5. 225° is in Quadrant III with 45° reference angle: (−√2/2, −√2/2).
  6. cos² θ = 1 − sin² θ = 1 − 3/4 = 1/4. Cosine is positive in Quadrant IV, so cos θ = 1/2.
  7. 390° is coterminal with 30° (subtract 360°), so sin 390° = 1/2.
  8. tan(π/2) is undefined because cosine is 0 there.
  9. sin² θ = 1 − 25/169 = 144/169. In Quadrant IV sine is negative, so sin θ = −12/13. Then tan θ = (−12/13)/(5/13) = −12/5.
  10. The coordinates have x negative and y positive, so the point is in Quadrant II. Equal absolute coordinates mean a 45° reference angle; the angle is 135°.
